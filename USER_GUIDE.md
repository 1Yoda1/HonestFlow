# HonestFlow 3.0 — руководство пользователя

> **HonestFlow** — Windows-приложение для диагностики, установки, настройки и обслуживания программных компонентов, необходимых для работы кассового места с ТС ПИоТ и маркировкой.
>
> Это руководство относится к ветке [`codex/remote-support`](https://github.com/1Yoda1/HonestFlow/tree/codex/remote-support). Возможности отдельных сборок могут отличаться. Описанные сервисные действия требуют соответствующего доступа и технических условий.

## 1. Режимы Free и Service

Программа доступна в двух режимах:

| Возможность | Free | Service |
|---|:---:|:---:|
| Запуск основного окна без регистрации | ✅ | — |
| Локальная проверка состояния рабочего места | ✅ | ✅ |
| Просмотр статусов компонентов, служб и локальных подключений | ✅ | ✅ |
| Подробная схема кассового узла | ✅ | ✅ |
| Сопоставление установленных версий с назначенными клиенту | Ограничено: нет серверной конфигурации | ✅ при наличии данных |
| Установка, обновление и переустановка компонентов | ❌ | ✅ при наличии разрешений |
| Управление службами и изменяющие операции | ❌ | ✅ при наличии разрешений |
| Автоматическое исправление проблем | ❌ | ✅ для поддерживаемых сценариев |
| Сервисные запросы и передача диагностики | Ограничено доступными локальными средствами | ✅ при наличии настроенного канала |

**Free не требует кода клиента, регистрации устройства или проверки лицензии.** Основное окно открывается сразу. Приложение может проверять наличие публичного обновления при запуске, но недоступность сервера обновлений не должна блокировать локальную диагностику.

**Service** включается после подключения к клиенту и подтверждения необходимых прав. Если ранее сохранялся вход, приложение может попытаться восстановить сервисное подключение после открытия главного окна.

## 2. Системные требования и подготовка

Для текущей сборки HonestFlow:

- компьютер с **64-разрядной Windows**;
- **Microsoft .NET 10 Desktop Runtime x64**;
- права администратора для установки, изменения служб и других операций обслуживания;
- для сервисного режима — соединение с сервером, действующий доступ и разрешения на соответствующие действия (допустимость автономной работы зависит от ранее полученного состояния лицензии);
- для установки и регистрации компонентов — доступные совместимые дистрибутивы, необходимые параметры клиента и корректно подключенное оборудование.

**Важно:** соответствие минимальным требованиям HonestFlow ещё не означает совместимость всех компонентов ТС ПИоТ, ЛМ ЧЗ, контроллера и драйвера АТОЛ. Перед установкой ориентируйтесь также на требования разработчиков этих компонентов и проверки самой программы.

Для максимально автоматической подготовки кассового места заранее подключите ККТ к компьютеру и убедитесь, что она доступна штатному драйверу. В используемом рабочем сценарии также предполагается открытая смена на кассе. Не следует выполнять регистрацию или вмешательство в кассовое ПО во время проведения расчётов.

## 3. Установка и первый запуск

### Где получить программу

Официальный сайт: **https://honestflow.ru/**. Скачивайте опубликованные сборки только из доверенного источника. Репозиторий проекта: https://github.com/1Yoda1/HonestFlow.

### Через установщик (рекомендуемый сценарий)

1. Скачайте официальный установщик HonestFlow, когда он опубликован для вашей версии.
2. Запустите его с необходимыми правами и следуйте шагам мастера.
3. Web Setup при необходимости загружает и устанавливает **.NET 10 Desktop Runtime x64**.
4. Завершите установку и запустите HonestFlow из меню «Пуск» или ярлыка.

Наличие проекта Web Setup в исходниках не гарантирует, что установщик уже опубликован на сайте.

### При получении отдельного HonestFlow.exe

1. Убедитесь, что установлен .NET 10 Desktop Runtime x64.
2. Поместите полученный `HonestFlow.exe` в постоянную локальную папку, доступную для обновления.
3. Запустите приложение. Если Windows запросит повышенные права, подтвердите их только для доверенной сборки.

### Что происходит при запуске

1. HonestFlow проверяет, не запущен ли уже другой экземпляр.
2. Выполняет публичную проверку обновления приложения.
3. Создаёт локальный контекст диагностики **Free**.
4. Открывает **MainWindow** без обязательного входа и регистрации.
5. Выполняет локальную диагностику компонентов.
6. Если раньше сохранялся сервисный вход, может попытаться восстановить его отдельно.

**Важно:** старое описание запуска через обязательный «пароль продавца» не соответствует текущему основному сценарию WPF-версии.

## 4. Главное окно и проверка состояния

В главном окне доступны разделы **«Главная»**, **«Инструменты»**, **«Компоненты»**, **«Журнал»** и диагностические представления. Видимость отдельных элементов и сервисных действий зависит от режима.

### Простое представление

В разделе **«Главная»** выберите **«Простой вид»**, чтобы увидеть общую оценку готовности рабочего места и короткое пояснение. Это удобный первый шаг для кассира или сотрудника магазина.

### Подробная схема

Нажмите **«Подробная схема»** или **«Показать подробности»**, чтобы увидеть отдельные компоненты и связи между ними. В схеме могут отображаться:

- ТС ПИоТ (ЕСМ);
- ККТ;
- локальный контроллер;
- ЛМ ЧЗ;
- ГИС МТ и каналы связи.

Цвет и текст статуса показывают результат проверки; линия между узлами отражает доступность связи. Наведите указатель на проблемную связь или откройте подробности элемента, чтобы получить пояснение.

### Повторная проверка

Нажмите **«Проверить снова»** после изменения настроек, перезапуска службы, восстановления сети или подключения кассы. Учитывайте время последней проверки: старый успешный результат не гарантирует, что компоненты работают прямо сейчас.

## 5. Диагностика и трактовка результатов

HonestFlow проверяет доступные локальные службы, интерфейсы API, состояния компонентов, связи и сведения о версиях. Состав проверок зависит от обнаруженного ПО, прав и режима работы.

| Отображаемое состояние | Что означает | Первые действия |
|---|---|---|
| **Готово / доступно** | Проверка компонента завершилась успешно | Дополнительные действия обычно не нужны |
| **Требуется внимание** | Обнаружено отклонение или неполная готовность | Откройте подробности, проверьте рекомендации |
| **Недоступно / ошибка** | Компонент или соединение не ответили должным образом | Проверьте питание, службы, подключение и журнал |
| **Нет данных / не проверено** | Программа не смогла получить надёжное подтверждение состояния | Проверьте доступность API и повторите диагностику |

**«Нет данных» не равняется «исправно».** Аналогично, успешный ответ службы не гарантирует корректность всех внутренних настроек компонента.

В Free показываются локально наблюдаемые данные. Сравнение с *назначенными клиенту* версиями и конфигурациями требует соответствующих серверных сведений и может быть недоступно до подключения Service.

## 6. Подключение HonestFlow Service

1. В главном окне нажмите **«Подключить Service»**.
2. В открывшемся окне подключения введите выданный ответственным сотрудником **код клиента**.
3. Если предложено, выберите вариант сохранения входа на этом компьютере.
4. Дождитесь проверки доступа, устройства и лицензии.
5. После успешного подключения в основном окне появятся разрешённые сервисные функции.

Если этот компьютер ещё не зарегистрирован, интерфейс может предложить указать **физический адрес торговой точки**, отправить заявку и позже нажать **«Проверить статус»**. Администратор рассматривает заявку и назначает доступ отдельно. Отправка заявки не означает немедленную активацию Service.

При отсутствии лицензии, отказе в доступе или ошибке соединения **Free остаётся доступным**. Если ранее сохранённый Service восстановить не получилось, используйте кнопку подключения повторно, когда условия будут выполнены.

### Если Service не подключается

- проверьте правильность кода клиента;
- убедитесь, что устройство зарегистрировано и допущено администратором;
- проверьте интернет и доступность сервера;
- если показана заявка, посмотрите её текущий статус;
- при ошибке лицензии или отключённом доступе обратитесь к ответственному за HonestFlow.

**Особый режим «Только установка».** В окне подключения предусмотрен ограниченный сервисный сценарий для установки и переустановки компонентов. Он не равнозначен полноценной авторизации Service и не открывает остальные действия.

## 7. Установка и настройка компонентов

HonestFlow Service работает с четырьмя основными группами компонентов:

| Компонент | Назначение |
|---|---|
| **ESM (ТС ПИоТ)** | Компонент кассового взаимодействия с ТС ПИоТ |
| **ЛМ ЧЗ** | Локальный модуль «Честного Знака» |
| **ЛМ Контроллер** | Локальный контроллер взаимодействия с ЛМ ЧЗ |
| **Драйвер АТОЛ** | Программное обеспечение для связи с поддерживаемой ККТ |

### Подготовка рабочего места

1. Подключите кассу и убедитесь, что она определяется штатным драйвером.
2. Подключите **Service** и выберите правильного клиента/рабочее место.
3. Откройте раздел **«Компоненты»**.
4. Проверьте список обнаруженных компонентов и версии. Если показана назначенная версия, сравните её с установленной.
5. Запустите доступное действие установки или обновления. В зависимости от сценария выберите только необходимые компоненты.
6. Дождитесь завершения и проверьте итоговое сообщение.
7. Нажмите **«Проверить снова»** и убедитесь, что необходимые компоненты и связи доступны.

В сервисном сценарии приложение может последовательно проверять драйвер АТОЛ, соединение с ККТ, обнаружение кассы в ESM, регистрацию ТС ПИоТ и состояние контролируемого канала. Если касса не обнаруживается, предусмотрена повторная проверка после перезапуска ESM.

**Ограничения:** автоматическая регистрация зависит от готовности локального API ESM, состояния драйвера и ККТ, параметров точки, лицензии и условий на конкретном стенде. Не воспринимайте успешную установку пакетов как подтверждение полностью готового кассового места.

### Переустановка

Используйте её, когда обычное обновление или восстановление недостаточно. Переустановка способна изменить данные и параметры установленного ПО: перед запуском проверьте выбранную организацию, необходимую резервную копию и предупреждения HonestFlow.

## 8. Автоматическое исправление (AutoFix)

AutoFix доступен только в Service с соответствующими разрешениями. Его задача — подобрать безопасное исправление под обнаруженную проблему, выполнить действие и **повторно проверить результат**.

1. Откройте **«Главная»** и выполните диагностику.
2. Если выявлена поддерживаемая проблема и есть нужные права, нажмите **«Исправить автоматически»**.
3. Следите за прогрессом и историей выполняемых шагов.
4. Если запрашивается подтверждение переустановки или выбранной организации, внимательно проверьте данные.
5. По завершении прочитайте результат повторной диагностики.

Текущие сценарии в коде включают операции со службами ESM, ЛМ ЧЗ и контроллера, выборочную установку, инициализацию или восстановление ЛМ ЧЗ и регистрацию ТС ПИоТ. **Доступность конкретного исправления зависит от обнаруженной проблемы, конфигурации и состояния рабочего места.**

AutoFix может остановиться с результатом «требуются действия пользователя», «исправить не удалось» или «операция отменена». Это штатные исходы, а не повод запускать исправление бесконечно. Расширенные сценарии, включая изменение сетевых настроек, переадресацию портов и настройку таймаутов, развиваются и не считаются универсально доступными возможностями текущей версии.

## 9. Компоненты, службы и журналы

### Компоненты

В разделе **«Компоненты»** отображаются названия обнаруженного ПО и его версии. В Service при наличии конфигурации клиента могут показываться назначенные версии и доступные действия обновления.

### Инструменты

В разделе **«Инструменты»** есть средства просмотра системного состояния, ссылок на папки компонентов и служб, журнала событий, установленных программ и сетевых подключений. Кнопки запуска, остановки и перезапуска служб относятся к изменяющим действиям и ограничены правами Service.

### Журнал

Раздел **«Журнал»** предназначен для просмотра сообщений HonestFlow. Локальные журналы приложения хранятся в `%ProgramData%\HonestFlow\logs`.

При обращении в поддержку полезно записать: время ошибки, название компонента, видимый статус, что происходило до ошибки и что уже было предпринято.

## 10. Диагностика для поддержки

В инструментах присутствует возможность собрать локальный диагностический архив. В зависимости от текущего режима и доступных функций отправка может потребовать Service и настроенного канала доставки.

1. Повторите проблему, если это безопасно.
2. Откройте раздел диагностики/инструментов.
3. Используйте доступную команду сбора архива (например, **«Собрать»**); при разрешённой отправке используйте **«Собрать и отправить»**.
4. Укажите описание проблемы, если приложение запросит его.
5. Перед передачей архива проверьте, что его содержимое допустимо отправлять получателю.

**Важно:** диагностические файлы могут содержать служебные сведения о рабочем месте. Не публикуйте их в открытых обсуждениях и не пересылайте посторонним. Маскирование данных снижает риски, но не гарантирует отсутствия чувствительной информации во всех сторонних логах.

## 11. Обновления

При старте HonestFlow проверяет публичный источник обновлений. Для загрузки требуется интернет. Если источник недоступен, локальная Free-диагностика может продолжить работу.

При обнаружении подходящего обновления следуйте сообщению программы. Не завершайте процесс принудительно во время применения обновления. Если установка сорвалась, запустите установленную версию повторно и проверьте журнал обновлений в `%ProgramData%\HonestFlow\update`.

Обновления компонентов ESM, ЛМ ЧЗ, контроллера и драйвера АТОЛ — **отдельные сервисные операции**, не равные обновлению самой программы HonestFlow.

## 12. Типичные проблемы

| Проблема | Что проверить |
|---|---|
| HonestFlow не запускается | Windows x64, .NET 10 Desktop Runtime x64, права, журнал, отсутствие второго экземпляра |
| Free открылся, но Service недоступен | Это нормально без подключения и разрешённой лицензии |
| «Нет данных» по ESM | Установлен ли ESM, запущены ли его службы, отвечает ли локальный API |
| ККТ не определяется | Физическое подключение, питание, драйвер АТОЛ, правильный интерфейс связи и отсутствие конкурирующих подключений |
| ЛМ ЧЗ не готов | Состояние службы, доступность локального API и настройки ЛМ ЧЗ |
| Не совпадают версии | Сравните установленные версии с назначенными в Service; не обновляйте компонент вслепую |
| Автоматическая регистрация не завершилась | Наличие ККТ в ESM, состояние ESM, параметры клиента и результат регистрации |
| AutoFix не помог | Прочитайте последний результат и историю шагов; проверьте журнал и обратитесь в поддержку |
| Обновление недоступно | Интернет, доступность источника и права записи в папку приложения |
| Заявка на устройство не одобрена | Проверьте её статус и обратитесь к администратору Service |

## 13. Безопасная эксплуатация

- Скачивайте HonestFlow и компоненты только из доверенных источников.
- Не вводите код клиента на чужом компьютере без согласования с владельцем лицензии.
- Перед сервисными действиями убедитесь, что выбрана правильная организация и рабочая точка.
- Не выключайте ПК и ККТ во время установки или регистрации, если нет аварийной необходимости.
- Не удаляйте вручную служебные папки, локальные идентификаторы и данные компонентов в попытке «сбросить лицензию».
