# HonestFlow — полное руководство пользователя

## 1. Что нужно получить до начала работы

Перед первым запуском у ответственного за развёртывание должны быть получены:

1. ссылка на папку загрузки HonestFlow либо готовый файл `HonestFlow.exe`;
2. пароль продавца (он же пароль точки);
3. при локальной эксплуатации — комплект конфигурации и папка `Distr`;
4. понимание, для какой торговой точки настраивается компьютер;
5. доступ в интернет хотя бы для первого получения конфигурации, лицензии и регистрационной заявки.

Пароль и лицензия — разные вещи. Пароль определяет клиента в списке точек. Лицензия после этого отдельно проверяет, разрешено ли именно этому клиенту и именно этому компьютеру выполнять операции HonestFlow.

Не скачивайте HonestFlow из случайных писем, мессенджеров и неофициальных сайтов. Используйте только ссылку или EXE, переданные ответственным за развёртывание.

## 2. Скачивание HonestFlow

### Если выдана ссылка на папку

1. Откройте ссылку, выданную администратором.
2. Если опубликовано несколько каталогов версий, откройте каталог с наибольшим номером версии.
3. Скачайте файл `HonestFlow.exe`.
4. Создайте отдельную локальную папку, например `C:\HonestFlow`.
5. Переместите скачанный EXE в эту папку.
6. Не запускайте программу прямо из архива, браузера или временной папки загрузок.

### Если выдан готовый EXE

1. Создайте отдельную папку для программы.
2. Скопируйте в неё `HonestFlow.exe`.
3. Если вместе с программой выданы конфигурационные файлы, положите их рядом с EXE, не переименовывая.
4. Если выдана папка `Distr`, также поместите её рядом с EXE.

У HonestFlow нет MSI и обычного мастера установки. Сам `HonestFlow.exe` и есть запускаемое приложение. Папка с EXE одновременно используется для локальной конфигурации, резервных дистрибутивов и автоматической замены EXE при обновлении, поэтому у программы должны быть права записи в эту папку.

## 3. Установка обязательного .NET 6 Desktop Runtime

HonestFlow собран для `net6.0-windows`. Чтобы он запустился, на компьютере заранее должен быть установлен **Microsoft .NET 6 Desktop Runtime x64**.

### Что именно скачивать

На официальной странице Microsoft [.NET 6](https://dotnet.microsoft.com/download/dotnet/6.0) найдите раздел **Desktop Runtime**, выберите **Windows x64** и скачайте установщик. Нужен именно Desktop Runtime x64:

- не ASP.NET Core Runtime;
- не обычный .NET Runtime без Desktop;
- не x86;
- SDK допустим, но для работы HonestFlow не требуется.

### Порядок установки

1. Закройте HonestFlow, если уже пытались его открыть.
2. Запустите скачанный установщик .NET 6 Desktop Runtime x64.
3. Подтвердите запрос контроля учётных записей Windows.
4. Нажмите **Install / Установить**.
5. Дождитесь сообщения об успешной установке.
6. Закройте установщик и снова запустите `HonestFlow.exe`.

Если Windows сообщает, что нужная среда уже установлена, повторная установка не требуется. Если без .NET 6 HonestFlow показывает системное окно с предложением скачать среду или сразу закрывается, сначала установите рантайм — сама программа ещё не запущена и скачать его за себя не может.

> Не путайте среды: .NET 6 Desktop Runtime запускает сам HonestFlow. После успешного входа HonestFlow может отдельно проверить, скачать и установить .NET 10 Desktop Runtime для обслуживаемого программного окружения. Установка .NET 10 не отменяет необходимость .NET 6 для текущей версии HonestFlow.

## 4. Первый запуск: полная последовательность

1. Нажмите правой кнопкой по `HonestFlow.exe`.
2. Выберите **«Запуск от имени администратора»**.
3. Подтвердите запрос Windows.
4. HonestFlow создаст или прочитает локальный идентификатор устройства `DeviceId`.
5. Программа проверит наличие новой версии HonestFlow.
6. Затем она загрузит список точек и требуемые версии компонентов.
7. После загрузки появится форма входа продавца.
8. Введите пароль точки либо выберите диагностический режим.
9. При правильном пароле HonestFlow определит клиента и проверит лицензию клиента и данного компьютера.
10. Если лицензия разрешает установку и обслуживание, программа проверит .NET 10 и при необходимости скачает и установит его.
11. После этого откроется главное окно и начнётся проверка состояния точки.

Не закрывайте стартовое окно и не запускайте второй экземпляр во время загрузки, обновления или проверки лицензии.

### Автоматическое обновление HonestFlow

При каждом старте программа проверяет опубликованные версии. Если найдена обязательная более новая версия:

1. HonestFlow сообщает номер новой версии;
2. скачивает новый `HonestFlow.exe` во временную папку `%ProgramData%\HonestFlow\update`;
3. проверяет, что файл существует и его версия не ниже объявленной;
4. закрывает текущий процесс;
5. сохраняет резервную копию старого EXE;
6. заменяет файл в папке приложения и запускается снова.

Не выключайте компьютер в этот момент. Если обновление не удалось, программа пытается вернуть резервную копию. Журнал применения обновления находится в `%ProgramData%\HonestFlow\update\apply_update.log`.

### Загрузка конфигурации

При запуске HonestFlow пытается скачать с настроенного ресурса:

- список клиентов и пароли точек — `ips_encrypted.json`;
- требуемые версии компонентов — `versions.json`;
- при необходимости настройки почты поддержки;
- позднее — лицензию и нужные установочные пакеты.

Если удалённая конфигурация недоступна, программа пробует локальные файлы рядом с EXE. Поэтому первый запуск без интернета возможен только при заранее подготовленной локальной конфигурации. Наличие локальной конфигурации само по себе не отменяет проверку лицензии.

## 5. Пароль продавца и выбор точки

Пароль продавца используется не как лицензия и не как пароль Windows. Он нужен, чтобы найти карточку конкретного клиента в загруженном списке точек.

### Обычный вход

1. В поле **«Пароль продавца»** введите пароль точки.
2. Нажмите **«Войти и проверить лицензию»**.
3. HonestFlow последовательно покажет:
   - проверку пароля;
   - найденного клиента;
   - получение `DeviceId`;
   - чтение и проверку лицензии;
   - итоговое решение о доступе.
4. При успешном определении клиента появится его название.

Если пароль не подошёл, программа напишет **«Неверный пароль продавца. Попробуйте ещё раз»** и снова покажет форму ввода. Проверьте раскладку, Caps Lock, пробелы и то, что пароль относится к нужной точке.

### Сохранённый вход

Если на этом компьютере уже выполнялся успешный вход, HonestFlow может предложить: **«Вы уже авторизованы под продавцом … Войти?»**.

- **Да** — использовать сохранённого клиента, но всё равно заново проверить лицензию;
- **Нет** — перейти к вводу другого пароля.

Сохранённый клиент не обходит лицензирование. Если его больше нет в текущей конфигурации или лицензию проверить не удалось, HonestFlow попросит пароль заново.

### Только диагностика

Нажатие **«Только диагностика»** пропускает вход. В этом режиме доступны базовые операции поддержки: сбор и отправка диагностики, установка/настройка RuDesktop и запрос помощи. Статусы точки, управление службами, установка компонентов и обслуживание остаются заблокированными.

## 6. Как работает лицензирование

После правильного пароля HonestFlow уже знает `ClientId`, но полноценный доступ ещё не выдан. Затем выполняется отдельная проверка лицензии.

### Что проверяется

1. При первом запуске компьютеру создаётся случайный постоянный `DeviceId`.
2. HonestFlow получает указатель на актуальную публикацию лицензии.
3. Загружает `licenses.json` и отдельную подпись `licenses.json.sig`.
4. Проверяет подпись ECDSA P-256/SHA-256 встроенным открытым ключом.
5. Ищет в манифесте клиента с тем же `ClientId`.
6. Внутри клиента ищет этот `DeviceId`.
7. Проверяет, включены ли клиент и устройство.
8. Сравнивает версию HonestFlow с минимально разрешённой.
9. Проверяет срок действия манифеста и автономный период.
10. Применяет разрешения `ViewAndRepair` и `InstallAndMaintenance`.

Закрытого ключа подписи в приложении нет. Ручное изменение `licenses.json` делает подпись недействительной и не открывает доступ.

### Первая регистрация устройства

На новом компьютере его `DeviceId`, как правило, ещё отсутствует в лицензии. Тогда происходит следующее:

1. пароль принимается и клиент определяется;
2. лицензия возвращает состояние **«Устройство не зарегистрировано»**;
3. HonestFlow просит проверить или ввести адрес торговой точки;
4. программа автоматически формирует регистрационную заявку с клиентом, `DeviceId`, именем компьютера, адресом точки и версией HonestFlow;
5. заявка отправляется через настроенный почтовый канал;
6. до подтверждения доступны только базовые диагностические функции;
7. ответственный сотрудник добавляет устройство в лицензию и публикует новую ревизию;
8. после подтверждения нажмите **«Обновить лицензию»** либо перезапустите HonestFlow;
9. если клиент, устройство и разрешения совпали, функции разблокируются.

Повторное нажатие не должно бесконечно дублировать одну и ту же заявку: состояние доставки сохраняется локально. Если заявка не отправляется, проверьте интернет и настройки почты, затем передайте ответственному `DeviceId` через штатный канал поддержки.

### Где хранится DeviceId

Идентификатор находится в `%ProgramData%\HonestFlow\device-identity\device-identity.dpapi` и защищён Windows DPAPI для данного компьютера. Не удаляйте и не копируйте этот файл вручную. После удаления, повреждения, переустановки Windows или переноса состояния может сформироваться новый `DeviceId`, который потребуется зарегистрировать повторно.

### Разрешения лицензии

| Разрешение | Что открывает |
|---|---|
| Базовый доступ | Диагностика, отправка логов, запрос помощи, установка и настройка RuDesktop |
| `ViewAndRepair` | Просмотр состояния точки, управление службами, восстановление служб и инициализация ЛМ ЧЗ, открытие локальных утилит |
| `InstallAndMaintenance` | Автоматическая установка, принудительная переустановка компонентов и восстановление базы ЛМ ЧЗ |

Даже при действующей лицензии кнопка остаётся выключенной, если нужное разрешение не назначено.

### Работа без интернета

После успешной онлайн-проверки подписанная лицензия сохраняется в `%ProgramData%\HonestFlow\license-cache`. При временном отсутствии сети HonestFlow может использовать только ранее проверенный кэш и только в течение `OfflineGraceHours`, заданного для клиента.

Если проверенного кэша нет или автономный период истёк, изменяющие систему функции блокируются. Восстановите интернет и нажмите **«Обновить лицензию»**.

### Все состояния лицензии

| Состояние | Значение | Действия пользователя |
|---|---|---|
| Лицензия действительна | Клиент, устройство, версия и срок подходят | Работайте с функциями, разрешёнными лицензией |
| Устройство не зарегистрировано | В лицензии клиента нет этого `DeviceId` | Укажите адрес, дождитесь обработки автоматической заявки, затем обновите лицензию |
| Клиент не найден | Для найденного по паролю `ClientId` нет записи в лицензии | Обратитесь к ответственному за конфигурацию и лицензии |
| Клиент отключён | Запись клиента есть, но выключена | Доступны базовые диагностические действия; обратитесь к администратору лицензий |
| Устройство отключено | `DeviceId` найден, но выключен | Обратитесь к администратору лицензий |
| Версия HonestFlow устарела | Текущая версия ниже минимальной | Восстановите интернет и перезапустите программу для обновления либо получите новый EXE |
| Манифест просрочен | Истёк общий срок публикации лицензии | Обратитесь к ответственному за выпуск лицензии |
| Автономный период истёк | Слишком давно не было успешной онлайн-проверки | Восстановите интернет и обновите лицензию |
| Лицензия недействительна | Ошибка структуры, подписи, источника или локального состояния | Не редактируйте файлы; соберите диагностику и обратитесь в поддержку |

### Кнопка «Обновить лицензию»

Используйте её после регистрации устройства, изменения разрешений, восстановления интернета или публикации новой лицензии. Кнопка повторно загружает манифест, проверяет подпись и немедленно применяет новое решение без повторного ввода пароля.

## 7. Подготовка и скачивание .NET 10 после лицензии

После входа HonestFlow проверяет .NET 10 Desktop Runtime только тогда, когда лицензия разрешает установку и обслуживание.

1. Программа проверяет установленную версию .NET 10.
2. Если нужной версии нет, проверяет архитектуру и свободное место.
3. Ищет пакет `windowsdesktop-runtime-10.0.10-win-x64.exe` в локальном кэше.
4. При отсутствии или повреждении скачивает пакет с опубликованного ресурса.
5. Проверяет пакет и запускает тихую установку.
6. Сообщает об успехе, ошибке или необходимости перезагрузки.

Кэш находится в `%ProgramData%\HonestFlow\dotnet-runtime`. Не закрывайте стартовое окно во время скачивания и установки. Если требуется перезагрузка, завершите текущую работу и перезагрузите Windows.

## 8. Назначение программы

HonestFlow — служебное Windows-приложение для подготовки, проверки и обслуживания рабочего места, использующего компоненты «Честного Знака». Программа объединяет в одном окне:

- проверку ЛМ ЧЗ, контроллера, ЕСМ, ККТ, связи с облаком и RuDesktop;
- установку отсутствующих или неподходящих по версии компонентов;
- запуск и перезапуск служб Windows;
- инициализацию и восстановление ЛМ ЧЗ;
- сбор диагностического архива и его отправку в поддержку;
- установку и настройку RuDesktop;
- автоматическую проверку лицензии и обновлений HonestFlow.

HonestFlow не заменяет установщики ЛМ ЧЗ, ЕСМ, контроллера и драйвера АТОЛ. Программа выбирает нужные операции и запускает штатные установщики в правильной последовательности.

## 9. Термины

| Термин | Значение |
|---|---|
| Точка | Рабочий компьютер конкретной торговой точки |
| ЛМ ЧЗ | Локальный модуль «Честного Знака» |
| ЕСМ | Компонент с оркестратором и экземплярами `esm-cm-*` |
| ККТ | Контрольно-кассовая техника и службы драйвера АТОЛ |
| Контроллер | Контроллер ЛМ ЧЗ (`lm-controller`) |
| RuDesktop | Средство удалённого подключения службы поддержки |
| Пароль продавца / пароль точки | Пароль, по которому HonestFlow определяет клиента и проверяет лицензию этой точки |

## 10. Общие требования к работе

После завершения первоначальной подготовки для работы требуются:

- Windows x64;
- установленный .NET 6 Desktop Runtime x64;
- права локального администратора для установки, переустановки, восстановления и управления службами;
- подключение к интернету для загрузки удалённой конфигурации, лицензии, дистрибутивов, обновлений и отправки почты;
- полученные у ответственного сотрудника `HonestFlow.exe`, эксплуатационная конфигурация и пароль точки.

Не перемещайте и не удаляйте находящиеся рядом служебные файлы. В локальном режиме рядом с EXE также находятся конфигурационные файлы и папка `Distr` с дистрибутивами.

> Важно: запускайте HonestFlow от имени администратора. Нажмите правой кнопкой по `HonestFlow.exe` и выберите **«Запуск от имени администратора»**, затем подтвердите запрос Windows. Без повышения прав диагностические функции могут работать, но изменяющие систему операции будут отклонены.

## 11. Краткий повторный запуск

1. Запустите `HonestFlow.exe` от имени администратора.
2. Дождитесь проверки обновлений и загрузки конфигурации.
3. Подтвердите сохранённого клиента или введите пароль продавца.
4. Дождитесь проверки лицензии.
5. Убедитесь, что в главном окне указано **«Авторизован: <название клиента>»**.
6. Дождитесь автоматической проверки состояния точки.

Если пароль неверен, появится сообщение «Доступ запрещён». Проверьте раскладку клавиатуры, Caps Lock и повторите ввод. Пароль не следует передавать посторонним или помещать в диагностические сообщения.

### Повторный вход другого продавца

Если предложение сохранённого входа показывает не ту точку, выберите **«Нет»** и введите пароль требуемой точки. Перед изменяющей системой операцией ещё раз проверьте название авторизованного клиента.

### Повторный запуск без пароля

Выберите **«Только диагностика»**. Позже можно нажать **«Войти как продавец»** и перейти в полноценный режим.

|---|---|

| Обслуживание точки | Открывает ручную переустановку компонентов и восстановление базы ЛМ ЧЗ |
| Открыть Драйвер ККТ | Запускает установленную утилиту драйвера ККТ |
| Открыть ЕСМ | Запускает установленное приложение ЕСМ |
| Журнал выполнения | Открывает текущий лог HonestFlow либо папку журналов |
| Оценить HonestFlow | Отправляет оценку приложения через настроенный почтовый канал |
| Обновить лицензию | Немедленно загружает и повторно проверяет лицензию |

Кнопка может быть неактивной, если функция не разрешена лицензией, не выполнен вход, не завершена другая операция или отсутствуют необходимые данные точки. Наведите указатель на неактивную кнопку: для лицензионного ограничения отображается пояснение.

### Панель «Состояние точки»

Она содержит строки **ЛМ ЧЗ**, **Контроллер**, **ЕСМ**, **ККТ**, **Связь с облаком** и **RuDesktop**. В каждой строке отображаются цвет, текст состояния и доступное действие.

| Цвет | Значение |
|---|---|
| Зелёный | Узел исправен |
| Жёлтый | Узел работает не полностью или требует внимания |
| Красный | Обнаружена ошибка или недоступность |
| Серый | Идёт проверка, данных недостаточно или функция недоступна |

Нажмите **«Подробнее →»**, чтобы увидеть общий отчёт: исходные статусы, принятые программой решения и доступные действия. Кнопка в конкретной строке выполняет действие, подходящее текущему состоянию: обновление, запуск, перезапуск, исправление, установка или запрос помощи.

## 13. Рекомендуемый повседневный сценарий

1. Запустите HonestFlow от имени администратора.
2. Войдите паролем своей точки.
3. Посмотрите итоговый цвет в заголовке и строки панели состояния.
4. Если всё зелёное, дополнительных действий не требуется.
5. При жёлтом или красном состоянии сначала нажмите кнопку действия в проблемной строке.
6. Затем нажмите **«Обновить статусы»** и проверьте результат.
7. Если проблема осталась, соберите диагностику и отправьте её в поддержку.

Во время длительной операции остальные конфликтующие действия блокируются. Дождитесь завершения: HonestFlow не запускает параллельно установку, восстановление, диагностику или другую длительную процедуру.

## 14. Проверка и установка компонентов

### Автоматическая установка

1. Войдите как продавец.
2. Нажмите **«Запустить установку»**.
3. Дождитесь завершения проверки и заполнения индикатора прогресса.
4. Разрешайте запуск штатных установщиков и подтверждайте запросы Windows, если они появляются.
5. После завершения HonestFlow автоматически обновит состояние точки.

Программа сравнивает фактическое состояние с конфигурацией выбранной точки и строит план для ЛМ ЧЗ, драйвера АТОЛ, ЕСМ и контроллера. Уже исправные компоненты без необходимости не переустанавливаются. Дистрибутивы берутся из локальной папки `Distr`, общего кэша или загружаются из настроенного удалённого источника.

Если показано «Установка не выполнена. Смотрите лог», откройте **«Журнал выполнения»**, затем соберите диагностику. Не запускайте повторную установку много раз подряд, не выяснив причину.

### Принудительная переустановка

Используйте её только когда обычная установка не помогла или это рекомендовал специалист поддержки.

1. Нажмите **«Обслуживание точки»**.
2. Выберите **«Переустановить компоненты»**.
3. Отметьте один или несколько компонентов: **ЛМ ЧЗ**, **Драйвер АТОЛ**, **ЕСМ**, **Контроллер ЛМ**.
4. Проверьте список в предупреждении и нажмите **«Да»**.
5. Дождитесь окончания и повторной проверки статусов.

Принудительная переустановка изменяет установленное ПО и может временно остановить связанные службы. Не выключайте компьютер и не завершайте HonestFlow во время операции.

## 15. Управление состоянием точки

### Обновление статусов

Нажмите **«Обновить статусы»**, чтобы заново проверить службы Windows и локальные интерфейсы компонентов. Используйте это после ручных изменений, перезапуска службы, установки или ожидания запуска компонента.

### Запуск и перезапуск служб

Если в строке узла есть известные службы, кнопка показывает **«Запустить»** при остановленной службе или **«Перезапуск»**, когда службы уже запущены.

1. Нажмите кнопку нужного узла.
2. Проверьте перечень служб и выбранное действие в окне подтверждения.
3. Подтвердите действие.
4. Дождитесь повторной проверки.

Перезапуск создаёт кратковременный перерыв в работе компонента. Не выполняйте его во время активной кассовой операции.

### Восстановление служб ЛМ ЧЗ

Если строка ЛМ ЧЗ предлагает **«Запустить»**, HonestFlow последовательно запускает `regime`, ожидает автоматического запуска `yenisei`, при необходимости запускает его вручную и затем ждёт готовности API ЛМ ЧЗ. Операция занимает не меньше нескольких десятков секунд.

### Инициализация ЛМ ЧЗ

Если строка ЛМ ЧЗ предлагает **«Исправить»**:

1. Убедитесь, что выбрана правильная точка.
2. Нажмите **«Исправить»**.
3. Подтвердите инициализацию.
4. Дождитесь повторного опроса.

Для операции в карточке точки должны быть настроены токен и ИНН. Токен в журнал не выводится. Если HonestFlow сообщает об отсутствии токена, обратитесь к администратору конфигурации.

### Восстановление базы ЛМ ЧЗ

Это сервисная операция для повреждённой или утраченной базы; не используйте её как обычный способ устранения любой ошибки.

1. Закройте кассовые операции, которые обращаются к ЛМ ЧЗ.
2. Нажмите **«Обслуживание точки»** → **«Восстановить базу ЛМ ЧЗ»**.
3. Дождитесь восстановления из доступного локального либо удалённого архива.
4. Проверьте обновившийся статус ЛМ ЧЗ.

Операция требует прав администратора, успешного входа и отдельного разрешения лицензии.

## 16. Диагностика

### Создание архива

1. Нажмите **«Собрать диагностику»**.
2. Выберите группы данных. По умолчанию отмечены все:
   - сведения о системе и статусы служб;
   - логи HonestFlow;
   - логи ЛМ ЧЗ;
   - логи ЕСМ;
   - лог ККТ / АТОЛ.
3. Нажмите **OK**. Должна быть выбрана хотя бы одна группа.
4. Проверьте автоматически найденный адрес точки или введите его вручную.
5. Дождитесь создания архива.
6. На вопрос об отправке выберите:
   - **Да** — отправить архив через настроенную электронную почту;
   - **Нет** — оставить архив локально и показать его в Проводнике.

Архив сохраняется в `%ProgramData%\HonestFlow\diagnostics`. Если почтовая отправка завершилась ошибкой, локальный архив сохраняется и показывается в Проводнике, когда это возможно.

### Что попадает в архив

| Группа | Содержимое |
|---|---|
| Система | Версия Windows и HonestFlow, компьютер, пользователь, свободное место, известные службы, лицензия и последний отчёт точки |
| HonestFlow | До шести последних файлов журнала |
| ЛМ ЧЗ | `regime.log`, `yenisei.log`, `lmcontroller.log` |
| ЕСМ | `esm-orchestrator.log` и свежий `esm-cm_*.log` |
| ККТ | `fptr10.log`, из которого также может определяться адрес точки |

Большинство продуктовых журналов ограничивается последними двумя днями. Отсутствующий лог не прерывает сбор: это отмечается в отчёте.

> Диагностический архив может содержать имя компьютера и пользователя Windows, адрес точки, идентификаторы устройств, сетевые параметры и продуктовые журналы. Перед передачей вне штатного канала поддержки проверьте содержимое архива. Не публикуйте его в открытом доступе.

## 17. RuDesktop и запрос помощи

### Установка RuDesktop

Если RuDesktop отсутствует или требует переустановки, в его строке появится **«Установить»** или **«Переустановить»**.

1. Войдите как продавец.
2. Нажмите соответствующую кнопку.
3. Проверьте версию и имя пакета в подтверждении.
4. Нажмите **«Да»** и разрешите повышение прав Windows.
5. Дождитесь запуска службы и появления ID.

При успешной установке HonestFlow покажет ID либо сообщит, что он пока не получен. Если требуется перезагрузка, выполните её после завершения остальных работ.

### Постоянный пароль

Когда RuDesktop установлен, но не настроен, HonestFlow предлагает применить постоянный пароль из карточки клиента. Введите пароль точки для подтверждения и выберите **«Настроить»**. Сам пароль RuDesktop в журнал HonestFlow не записывается.

Если выбрать **«Позже»** или **«Нет»**, предложение появится повторно. Без установленного RuDesktop, его ID и настроенного постоянного пароля запрос помощи недоступен.

### Отправка запроса помощи

1. Нажмите **«Запросить помощь»** в диагностическом режиме или в строке RuDesktop.
2. При необходимости настройте RuDesktop и дождитесь получения ID.
3. Выберите тип проблемы:
   - ошибка проверки кода маркировки;
   - ошибка ККТ;
   - ошибка кассового ПО;
   - другое.
4. Проверьте или введите адрес торговой точки.
5. Опишите проблему: что делали, какой результат ожидали, какое сообщение получили и когда возникла ошибка.
6. Нажмите **«Отправить»** и дождитесь сообщения «Заявка отправлена».

## 18. Журналы и служебные файлы

- **«Журнал выполнения»** открывает текущий лог либо папку с логами HonestFlow.
- Установочные пакеты кэшируются в `%ProgramData%\HonestFlow\cache\installers`.
- Диагностические архивы находятся в `%ProgramData%\HonestFlow\diagnostics`.
- Лицензия, идентификатор устройства и прочее состояние находятся под `%ProgramData%\HonestFlow`.

Не удаляйте служебное состояние без указания администратора: смена идентификатора устройства может потребовать повторной регистрации. Не отправляйте конфигурацию, лицензии, журналы и кэш посторонним.

## 19. Типовые проблемы

### HonestFlow не запускается

1. Проверьте, что используется Windows x64.
2. Установите .NET 6 Desktop Runtime x64.
3. Запустите EXE от имени администратора.
4. Если защитное ПО блокирует файл, не отключайте защиту самостоятельно — передайте сообщение ответственному администратору.

### Не проходит вход

- проверьте раскладку, Caps Lock и отсутствие пробелов;
- убедитесь, что используете пароль именно этой точки;
- восстановите интернет, если удалённая конфигурация ещё не была получена;
- при повторной ошибке используйте диагностический режим и обратитесь к администратору.

### Все действия недоступны

Проверьте, выполнен ли вход, завершилась ли проверка лицензии и не идёт ли другая длительная операция. Наведите указатель на кнопку. Затем нажмите **«Обновить лицензию»**.

### Статусы не обновляются

Подождите завершения установки или запуска служб, затем нажмите **«Обновить статусы»**. Если ошибка сохраняется, откройте подробный отчёт и соберите диагностику.

### Не отправляется диагностика или заявка

Локальный архив диагностики всё равно должен сохраниться. Проверьте интернет, наличие разрешения лицензии и настройки почтового канала. Для заявки помощи дополнительно нужны установленный и настроенный RuDesktop и полученный ID.

### RuDesktop установлен, но ID отсутствует

Подождите 15–30 секунд, обновите статусы и проверьте, запущена ли служба RuDesktop. При необходимости используйте кнопку запуска/перезапуска. Если ID не появился, соберите диагностику.

### Программа просит дождаться другой операции

HonestFlow выполняет только одну длительную операцию одновременно. Не запускайте второй экземпляр для обхода ограничения. Дождитесь завершения текущего процесса.

## 20. Правила безопасной работы

- Всегда проверяйте название авторизованной точки перед установкой, инициализацией или восстановлением.
- Не перезапускайте службы и не переустанавливайте кассовые компоненты во время активной продажи.
- Не выключайте компьютер и не завершайте HonestFlow во время изменения системы.
- Не запускайте принудительную переустановку и восстановление базы без причины.
- Не разглашайте пароли, токены, конфигурационные файлы и диагностические архивы.
- Не изменяйте содержимое `%ProgramData%\HonestFlow` вручную.
- После любой сервисной операции обновите статусы и убедитесь, что нужные узлы стали зелёными.
- При неясной или повторяющейся ошибке сначала соберите диагностику, затем обратитесь в поддержку.

## 21. Полный маршрут от чистого компьютера до готовой точки

1. Получить официальный `HonestFlow.exe`, пароль точки и при необходимости локальную конфигурацию.
2. Создать отдельную папку и положить туда EXE.
3. Скачать и установить Microsoft .NET 6 Desktop Runtime x64.
4. Запустить HonestFlow от имени администратора.
5. Дождаться проверки и, если требуется, автоматического скачивания обновлённого HonestFlow.
6. Дождаться загрузки списка точек и версий компонентов.
7. Ввести пароль продавца.
8. Проверить, что программа определила правильного клиента.
9. Дождаться получения `DeviceId` и проверки подписанной лицензии.
10. Если устройство не зарегистрировано — указать адрес точки и дождаться отправки заявки.
11. После добавления устройства ответственным сотрудником нажать **«Обновить лицензию»**.
12. Проверить, что выданы нужные разрешения `ViewAndRepair` и/или `InstallAndMaintenance`.
13. Дождаться проверки, скачивания и установки .NET 10, если программа сочтёт это необходимым.
14. В главном окне нажать **«Обновить статусы»** или дождаться автоматического опроса.
15. Нажать **«Запустить установку»** и дождаться загрузки/запуска нужных дистрибутивов.
16. После установки снова проверить все узлы.
17. Настроить RuDesktop и убедиться, что получен ID.
18. Если остались ошибки — открыть **«Подробнее»**, собрать диагностику и отправить запрос помощи.
19. Перед завершением убедиться, что нужные узлы зелёные и в строке состояния нет незавершённой операции.

## 22. Краткая памятка

**Обычная проверка:** запуск от администратора → вход → просмотр статусов → действие в проблемной строке → обновление статусов.

**Установка:** вход → «Запустить установку» → дождаться завершения → проверить статусы.

**Если не помогло:** «Подробнее» → «Собрать диагностику» → выбрать данные → проверить адрес → отправить архив.

**Удалённая помощь:** настроить RuDesktop → получить ID → «Запросить помощь» → описать проблему → отправить.
