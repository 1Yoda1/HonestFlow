## Уточнение для задачи по сайту — 3 ноября 2026

- `Infrastructure/ConnectionRequestNotifier.cs`: при настроенном SMTP содержимое заявки, включая IP и User-Agent, направляется в письме. Фактические SMTP-провайдер, адрес получателя, срок хранения и местонахождение почты определяются внешней конфигурацией и не установлены. В коде есть значение адреса по умолчанию; считать его фактическим получателем нельзя. Целесообразность передачи IP и User-Agent следует отдельно обосновать.
- `Program.cs`: обработка `X-Forwarded-For` включена для доверенных loopback-прокси; лимит используется после обработки заголовков. Надёжность зависит от действительной конфигурации Caddy и сетевого доступа, которые в рамках задания не проверялись.
- `site/app.js`: запрос выполняется через JSON POST на `/api/connection-requests`; кнопка блокируется на время запроса и после успеха, при ошибке разблокируется. Уведомление формы использует `role=status` и `aria-live=polite`. Honeypot на стороне сервера возвращает 204.
- Контракт `CreateConnectionRequest` проверяет длину телефона от 3 до 40 символов, но не устанавливает содержательную проверку номера; поле города на сайте обязательно, в API — необязательно. Это потенциальные расхождения, а не доказательство эксплуатации.
